Tools

  • tokenscope

    Waste finder and token flame graph for AI coding agents

    ccusage tells you what you spent. tokenscope tells you what you wasted, and how to stop it.

    npx @mintwork/tokenscope

  • honest-tests

    Fake-test detector and mutation testing for AI coding agents

    Your AI wrote 200 tests. Many of them can't fail. honest-tests finds them, and proves it by breaking your code and watching the tests stay green.

    npx @mintwork/honest-tests

  • wcag-audit-skill

    WCAG 2.2 accessibility audit skill and CLI

    AI ships inaccessible UIs. This makes your agent find the barriers, verify each one, and fix them with minimal, explained changes.

    npx @mintwork/wcag-audit-skill

  • agent-ready

    Agent readiness score for repositories

    Score how well Claude Code, Codex and Cursor can work in your repo, then auto-fix the gaps.

    npx @mintwork/agent-ready

How we build

  • One problem, one tool. Small, focused tools beat sprawling platforms.
  • Honest output. Estimates are labeled as estimates, and nothing is inflated to look impressive.
  • Local-first. Your code and data stay on your machine unless you ask otherwise.
  • Light footprint. Few dependencies, fast startup, nothing running in the background.
  • Verifiable releases. Every package is built in CI and published with signed npm provenance.
  • Open by default. MIT licensed, with issues and pull requests welcome.
